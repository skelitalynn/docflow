下面按你截图的“**表头说明 + 字段明细表**”格式，给出基于 P0（必做 MVP）需求的**全部数据表**（可直接放进数据库设计章节）。

> 说明：**presence 在线成员**属于弱实时状态，建议放 **内存/Redis**，P0 不落库，因此不在表清单内。

------

## 1）T_User（用户表）

**表说明**：本表记录系统用户的账号信息、角色、状态与基础资料（昵称/头像/联系方式）。

| 中文字段名 | 英文字段名    | 类型         | 约束         | 备注                           |
| ---------- | ------------- | ------------ | ------------ | ------------------------------ |
| 用户ID     | user_id       | bigint       | NOT NULL, PK | 主键                           |
| 邮箱       | email         | varchar(128) | UNIQUE, NULL | 登录/联系渠道（邮箱注册）      |
| 手机号     | phone         | varchar(32)  | UNIQUE, NULL | 登录/联系渠道（手机号注册）    |
| 密码哈希   | password_hash | varchar(255) | NOT NULL     | bcrypt/argon2 结果             |
| 系统角色   | system_role   | tinyint      | NOT NULL     | 1=Admin，2=User                |
| 昵称       | nickname      | varchar(64)  | NULL         | 个人资料昵称                   |
| 头像URL    | avatar_url    | varchar(255) | NULL         | 头像上传地址（P1 可选）        |
| 状态       | status        | tinyint      | NOT NULL     | 1=正常，2=冻结，3=封禁         |
| 创建时间   | created_at    | datetime     | NOT NULL     |                                |
| 更新时间   | updated_at    | datetime     | NOT NULL     |                                |

------

## 2）T_Password_Reset（密码重置表）

**表说明**：本表记录找回/重置密码的一次性凭证（验证码/邮件链接 token 均可映射为 token）。

| 中文字段名 | 英文字段名 | 类型         | 约束         | 备注                |
| ---------- | ---------- | ------------ | ------------ | ------------------- |
| 记录ID     | reset_id   | bigint       | NOT NULL, PK | 主键                |
| 用户ID     | user_id    | bigint       | NOT NULL, FK | 关联 T_User.user_id |
| 凭证哈希   | token_hash | varchar(255) | NOT NULL     | 不存明文 token      |
| 过期时间   | expires_at | datetime     | NOT NULL     |                     |
| 是否已使用 | is_used    | tinyint      | NOT NULL     | 0=未用，1=已用      |
| 创建时间   | created_at | datetime     | NOT NULL     |                     |
| 使用时间   | used_at    | datetime     | NULL         |                     |

------

## 3）T_Folder（文件夹表）

**表说明**：本表记录用户的文件夹分类结构（支持多级）。

| 中文字段名 | 英文字段名    | 类型        | 约束         | 备注                    |
| ---------- | ------------- | ----------- | ------------ | ----------------------- |
| 文件夹ID   | folder_id     | bigint      | NOT NULL, PK | 主键                    |
| 所属用户ID | owner_user_id | bigint      | NOT NULL, FK | 关联 T_User.user_id     |
| 父文件夹ID | parent_id     | bigint      | NULL, FK     | 关联 T_Folder.folder_id |
| 文件夹名   | name          | varchar(64) | NOT NULL     | 建议同层唯一            |
| 是否删除   | is_deleted    | tinyint     | NOT NULL     | 0/1（或用 deleted_at）  |
| 创建时间   | created_at    | datetime    | NOT NULL     |                         |
| 更新时间   | updated_at    | datetime    | NOT NULL     |                         |

> 文档分类支持“文件夹 + 标签”并存；标签通过 `T_Tag` 与 `T_Doc_Tag` 维护。

## 4）T_Document（文档主表）

**表说明**：本表记录文档的标题、内容、归属、乐观锁版本号与软删除信息。

| 中文字段名   | 英文字段名 | 类型         | 约束         | 备注                                |
| ------------ | ---------- | ------------ | ------------ | ----------------------------------- |
| 文档ID       | doc_id     | bigint       | NOT NULL, PK | 主键                                |
| 标题         | title      | varchar(200) | NOT NULL     | 默认“未命名”                        |
| 内容         | content    | longtext     | NOT NULL     | 富文本/Markdown/纯文本              |
| 内容格式     | content_format | tinyint  | NOT NULL     | 1=富文本，2=Markdown，3=纯文本      |
| 创建者ID     | creator_id | bigint       | NOT NULL, FK | 关联 T_User.user_id                 |
| 当前Owner ID | owner_id   | bigint       | NOT NULL, FK | 关联 T_User.user_id（冗余便于查询） |
| 所属文件夹ID | folder_id  | bigint       | NULL, FK     | 关联 T_Folder.folder_id             |
| 文档版本号   | version    | int          | NOT NULL     | 乐观锁：每次保存 +1                 |
| 是否删除     | is_deleted | tinyint      | NOT NULL     | 0/1                                 |
| 删除时间     | deleted_at | datetime     | NULL         | 软删除时间                          |
| 创建时间     | created_at | datetime     | NOT NULL     |                                     |
| 更新时间     | updated_at | datetime     | NOT NULL     |                                     |

------

## 5）T_Tag（标签表）

**表说明**：本表记录用户自定义标签，用于文档分类、筛选与搜索过滤。

| 中文字段名 | 英文字段名    | 类型        | 约束         | 备注                    |
| ---------- | ------------- | ----------- | ------------ | ----------------------- |
| 标签ID     | tag_id        | bigint      | NOT NULL, PK | 主键                    |
| 所属用户ID | owner_user_id | bigint      | NOT NULL, FK | 关联 T_User.user_id     |
| 标签名     | name          | varchar(64) | NOT NULL     | 同一用户下唯一          |
| 创建时间   | created_at    | datetime    | NOT NULL     |                         |
| 更新时间   | updated_at    | datetime    | NOT NULL     |                         |

**建议约束**

- UNIQUE(owner_user_id, name)：同一用户下标签名不重复

## 8）T_Doc_Member（文档成员/ACL 表）

**表说明**：本表记录文档与用户的权限关系（Owner/Editor/Viewer），是权限校验与列表/搜索过滤的核心。

| 中文字段名   | 英文字段名 | 类型     | 约束         | 备注                        |
| ------------ | ---------- | -------- | ------------ | --------------------------- |
| 记录ID       | member_id  | bigint   | NOT NULL, PK | 主键                        |
| 文档ID       | doc_id     | bigint   | NOT NULL, FK | 关联 T_Document.doc_id      |
| 用户ID       | user_id    | bigint   | NOT NULL, FK | 关联 T_User.user_id         |
| 文档权限角色 | doc_role   | tinyint  | NOT NULL     | 1=Owner，2=Editor，3=Viewer |
| 授权者ID     | granted_by | bigint   | NOT NULL, FK | 关联 T_User.user_id         |
| 创建时间     | created_at | datetime | NOT NULL     |                             |
| 更新时间     | updated_at | datetime | NOT NULL     |                             |

**关键约束（写进备注/实现必须落地）**

- UNIQUE(doc_id, user_id)：同一文档同一用户仅一条权限记录
- 至少 1 个 Owner：禁止移除/降级最后一个 Owner（业务约束）

## 10）T_Comment（评论表）

**表说明**：本表记录文档的块/段落级评论与回复线程。

| 中文字段名 | 英文字段名      | 类型        | 约束         | 备注                   |
| ---------- | --------------- | ----------- | ------------ | ---------------------- |
| 评论ID     | comment_id      | bigint      | NOT NULL, PK | 主键                   |
| 文档ID     | doc_id          | bigint      | NOT NULL, FK | 关联 T_Document.doc_id |
| 线程ID     | thread_id       | bigint      | NOT NULL     | 同一线程相同 thread_id |
| 父评论ID   | parent_id       | bigint      | NULL, FK     | 回复指向 comment_id    |
| 作者ID     | author_id       | bigint      | NOT NULL, FK | 关联 T_User.user_id    |
| 锚点块ID   | block_id        | varchar(64) | NULL         | 块级锚点（推荐）       |
| 段落序号   | paragraph_index | int         | NULL         | 段落锚点（可选）       |
| 评论内容   | content         | text        | NOT NULL     |                        |
| 状态       | status          | tinyint     | NOT NULL     | 1=正常，2=删除         |
| 创建时间   | created_at      | datetime    | NOT NULL     |                        |
| 更新时间   | updated_at      | datetime    | NOT NULL     |                        |

> thread_id 生成方式二选一：
> A) 主评论 thread_id = 自己 comment_id（插入后回填）
> B) 单独生成 thread_id（雪花/序列）
