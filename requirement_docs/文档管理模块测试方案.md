# 文档管理模块测试方案

本文档用于验证“文档管理模块”功能（创建/编辑、模板库、自动保存与恢复、分类、全文/高级搜索与排序）。测试以 Postman 为主，也可使用 curl/PowerShell。

------

## 1. 测试范围

- 文档创建与编辑（富文本/Markdown/纯文本）
- 模板库（创建/复用/公开模板）
- 自动保存与恢复
- 文档分类（文件夹 + 标签）
- 搜索（关键字 + 作者/日期/标签）
- 搜索结果排序

不包含：前端富文本编辑器 UI、OT/CRDT、版本历史等 P1/P2 功能。

------

## 2. 环境与前置条件

- 后端服务已启动：`http://localhost:8080`
- 数据库可用且已包含文档相关表：
  - `t_document` 含 `content_format` 字段
  - `t_doc_template` / `t_tag` / `t_doc_tag` 表已创建
- `application.properties` 中 `spring.jpa.hibernate.ddl-auto=update` 可自动补表，但正式环境建议执行 `db/schema.mysql.sql`

------

## 3. 通用变量

在 Postman 环境变量中设置：

- `baseUrl` = `http://localhost:8080`
- `tokenA` / `tokenB`：用户 A/B 登录后的 token
- `docId` / `folderId` / `tagId` / `templateId`：测试过程中保存的 ID

通用 Header：

- `Authorization: Bearer {{tokenA}}`
- `Content-Type: application/json`

------

## 4. 测试数据准备

### 4.1 注册与登录

创建用户 A/B，登录并保存 token：

```http
POST {{baseUrl}}/auth/register
Content-Type: application/json

{"email":"usera@example.com","password":"usera123","nickname":"UserA"}
```

```http
POST {{baseUrl}}/auth/login
Content-Type: application/json

{"account":"usera@example.com","password":"usera123"}
```

记录响应中的 token 到 `tokenA`。用户 B 同理，保存 `tokenB`。

### 4.2 创建文件夹/标签/模板

```http
POST {{baseUrl}}/folders
Authorization: Bearer {{tokenA}}
Content-Type: application/json

{"name":"测试文件夹"}
```

```http
POST {{baseUrl}}/tags
Authorization: Bearer {{tokenA}}
Content-Type: application/json

{"name":"标签A"}
```

```http
POST {{baseUrl}}/templates
Authorization: Bearer {{tokenA}}
Content-Type: application/json

{
  "title":"模板A",
  "description":"用于文档初始化",
  "content":"<p>模板正文</p>",
  "format":"RICH_TEXT",
  "isPublic":true
}
```

记录返回的 `folderId` / `tagId` / `templateId`。

------

## 5. 测试用例

### 5.1 文档创建与编辑

**TC-01 创建文档（默认格式）**  
接口：`POST /docs`  
请求：
```http
POST {{baseUrl}}/docs
Authorization: Bearer {{tokenA}}
Content-Type: application/json

{"title":"Doc-A","content":"初始内容"}
```
期望：
- 返回 200
- `version=1`
- `format=RICH_TEXT`（默认）
- 记录 `docId`

**TC-02 使用模板创建文档**  
接口：`POST /docs`  
请求：
```http
POST {{baseUrl}}/docs
Authorization: Bearer {{tokenA}}
Content-Type: application/json

{"templateId": {{templateId}}}
```
期望：
- 返回 200
- `title/content/format` 继承模板

**TC-03 创建文档并绑定文件夹/标签**  
请求：
```http
POST {{baseUrl}}/docs
Authorization: Bearer {{tokenA}}
Content-Type: application/json

{
  "title":"Doc-B",
  "content":"内容B",
  "folderId": {{folderId}},
  "tagIds": [{{tagId}}]
}
```
期望：
- 文档创建成功
- 通过 `/docs/{id}/tags` 可看到标签

**TC-04 获取文档详情（恢复）**  
接口：`GET /docs/{id}`  
期望：
- 返回最新保存的内容
- `role` 正确（Owner/Editor/Viewer）

**TC-05 编辑文档（版本递增）**  
接口：`PUT /docs/{id}`  
请求：
```http
PUT {{baseUrl}}/docs/{{docId}}
Authorization: Bearer {{tokenA}}
Content-Type: application/json

{"content":"更新内容","baseVersion":1,"format":"RICH_TEXT"}
```
期望：
- `version` 增加
- 返回 `format` 与请求一致

**TC-06 并发冲突（409）**  
重复使用旧 `baseVersion` 调用 `PUT /docs/{id}`  
期望：
- 返回 409
- 响应包含 `currentVersion`

**TC-07 自动保存**  
接口：`PUT /docs/{id}/autosave`  
请求与 TC-05 类似  
期望：
- `version` 增加
- 重新 `GET /docs/{id}` 内容一致

**TC-08 重命名**  
接口：`PUT /docs/{id}/title`  
请求：
```http
PUT {{baseUrl}}/docs/{{docId}}/title
Authorization: Bearer {{tokenA}}
Content-Type: application/json

{"title":"Doc-A-Renamed"}
```
期望：
- 返回新标题

**TC-09 删除文档**  
接口：`DELETE /docs/{id}`  
期望：
- 返回 `{"message":"ok"}`
- 之后 `GET /docs/{id}` 返回 404
- 列表/搜索中不可见

**TC-10 富文本内容保存**  
请求 `POST /docs` 或 `PUT /docs/{id}`，内容为 HTML  
期望：
- 原样存储（注意：未做 XSS 清洗）

------

### 5.2 模板库

**TC-11 创建模板**  
接口：`POST /templates`  
期望：模板创建成功，返回 `templateId`

**TC-12 模板列表**  
接口：`GET /templates?page=0&size=20`  
期望：返回公开模板 + 自己的私有模板

**TC-13 更新模板**  
接口：`PUT /templates/{id}`  
期望：内容/描述/公开性更新成功

**TC-14 删除模板**  
接口：`DELETE /templates/{id}`  
期望：模板删除成功，后续 `GET` 返回 404

**TC-15 公开模板可被他人访问**  
用户 B 调用 `GET /templates/{id}`  
期望：可访问公开模板

------

### 5.3 分类与列表（文件夹 + 标签）

**TC-16 文档列表按文件夹筛选**  
接口：`GET /docs?folderId={{folderId}}`  
期望：只返回该文件夹下有权限文档

**TC-17 文档列表按标签筛选**  
接口：`GET /docs?tagId={{tagId}}`  
期望：只返回绑定该标签的文档

**TC-18 列表排序**  
接口：`GET /docs?sortBy=title&order=asc`  
期望：按标题升序返回

**TC-19 删除非空文件夹失败**  
文件夹下存在文档时调用 `DELETE /folders/{id}`  
期望：返回 400（Folder not empty）

**TC-20 标签删除后关联清理**  
删除标签后查询 `/docs/{id}/tags`  
期望：该标签不再出现

------

### 5.4 搜索（全文/高级/排序）

**TC-21 关键字搜索（LIKE）**  
接口：`GET /search?q=关键字`  
期望：标题/内容含关键字的文档返回（ACL 过滤）

**TC-22 高级搜索（作者 + 日期范围）**  
接口：  
`GET /search?q=doc&authorId={{userId}}&from=2025-01-01T00:00:00&to=2030-01-01T00:00:00`  
期望：命中文档

**TC-23 标签过滤搜索**  
接口：`GET /search?tagId={{tagId}}`  
期望：只返回绑定该标签的文档

**TC-24 搜索排序**  
接口：`GET /search?q=doc&sortBy=createdAt&order=asc`  
期望：按创建时间升序排序

------

### 5.5 权限与异常

**TC-25 未登录访问**  
任意文档接口不带 token  
期望：401

**TC-26 无权限访问**  
用户 B 未被分享文档时访问 `GET /docs/{id}`  
期望：403

**TC-27 ACL 变更生效**  
使用 `/docs/{id}/members` 给用户 B 分配 Viewer，再访问  
期望：B 可查看；移除后立即不可访问
