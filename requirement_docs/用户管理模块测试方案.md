# 用户管理模块测试方案（Postman + PowerShell）

本文档用于完整验证用户管理模块的功能实现，包含 Postman 操作步骤与可直接执行的 PowerShell 测试命令。

## 1. 测试范围

- 用户注册与登录（邮箱/手机号）
- 密码找回与重置
- 用户资料与联系方式修改
- 头像上传与访问
- 系统角色（管理员）管理
- 文档 ACL（Owner/Editor/Viewer）
- 操作审计日志（用户/文档）
- 权限与异常场景（401/403/400/409）

## 2. 前置准备

### 2.1 服务与数据库

- MySQL 已创建数据库并导入 `db/schema.mysql.sql`
- 后端服务运行在 `http://localhost:8080`

### 2.2 管理员初始化（建议）

在 `src/main/resources/application.properties` 中配置：

```
docflow.bootstrap.enabled=true
docflow.bootstrap.admin-email=admin@example.com
docflow.bootstrap.admin-phone=
docflow.bootstrap.admin-password=admin123
docflow.bootstrap.admin-nickname=admin
```

启动一次后可将 `docflow.bootstrap.enabled=false` 关闭。

## 3. Postman 测试（推荐）

### 3.1 创建环境变量

在 Postman 环境中创建：

- `baseUrl` = `http://localhost:8080`
- `token` = （登录后自动填充）
- `adminToken` = （管理员登录后自动填充）
- `userId` / `userBId` / `docId` = 用于后续接口保存

### 3.2 登录后自动保存 token

在登录请求（`/auth/login`）的 Tests 中添加：

```javascript
const data = pm.response.json();
pm.environment.set("token", data.token);
pm.environment.set("userId", data.user.id);
```

管理员登录也可保存：

```javascript
const data = pm.response.json();
pm.environment.set("adminToken", data.token);
```

### 3.3 JSON 格式要求

Postman 中 Body 必须是 **raw → JSON**，示例：

```json
{
  "email": "usera@example.com",
  "password": "usera123",
  "nickname": "UserA"
}
```

注意：JSON 字段必须用双引号包住，且 URL 不要和 JSON 混在一起。

## 4. 测试用例（Postman 示例 + PowerShell）

### 4.1 用户注册与登录

#### TC-01 邮箱注册

- Method: `POST`
- URL: `{{baseUrl}}/auth/register`
- Body:
```json
{
  "email": "usera@example.com",
  "password": "usera123",
  "nickname": "UserA"
}
```
- 期望：200，返回 `token` 与 `user`

PowerShell：
```bash
curl.exe -X POST "http://localhost:8080/auth/register" -H "Content-Type: application/json" -d '{"email":"usera@example.com","password":"usera123","nickname":"UserA"}'
```

#### TC-02 手机号注册

- Body:
```json
{
  "phone": "13800000001",
  "password": "userb123",
  "nickname": "UserB"
}
```
- 期望：200

#### TC-03 登录

- Method: `POST`
- URL: `{{baseUrl}}/auth/login`
- Body:
```json
{
  "account": "usera@example.com",
  "password": "usera123"
}
```
- 期望：200，保存 token

PowerShell：
```bash
curl.exe -X POST "http://localhost:8080/auth/login" -H "Content-Type: application/json" -d '{"account":"usera@example.com","password":"usera123"}'
```

#### TC-04 重复邮箱注册（异常）

- 期望：400，提示 Email 已注册

### 4.2 找回与重置

#### TC-05 忘记密码

- Method: `POST`
- URL: `{{baseUrl}}/auth/forgot`
- Body:
```json
{
  "account": "usera@example.com"
}
```
- 期望：200，返回 `resetToken`

#### TC-06 重置密码

- Method: `POST`
- URL: `{{baseUrl}}/auth/reset`
- Body:
```json
{
  "resetToken": "<TOKEN>",
  "newPassword": "usera456"
}
```
- 期望：200

### 4.3 用户资料与联系方式

#### TC-07 获取个人资料

- Method: `GET`
- URL: `{{baseUrl}}/users/me`
- Header: `Authorization: Bearer {{token}}`
- 期望：200

#### TC-08 修改昵称

- Method: `PUT`
- URL: `{{baseUrl}}/users/me`
- Body:
```json
{
  "nickname": "UserA-Updated"
}
```
- 期望：200

#### TC-09 修改邮箱/手机号

- Body:
```json
{
  "email": "usera_new@example.com",
  "phone": "13800000009"
}
```
- 期望：200

### 4.4 头像上传

#### TC-10 上传头像

- Method: `POST`
- URL: `{{baseUrl}}/users/me/avatar`
- Header: `Authorization: Bearer {{token}}`
- Body: form-data
  - key: `file`
  - value: 选择一张本地图片
- 期望：200，返回 `avatarUrl`

#### TC-11 访问头像

在浏览器访问 `http://localhost:8080/avatars/<filename>`

### 4.5 系统角色管理

#### TC-12 管理员调整用户角色

- Method: `PUT`
- URL: `{{baseUrl}}/admin/users/{{userId}}/role`
- Header: `Authorization: Bearer {{adminToken}}`
- Body:
```json
{
  "role": "ADMIN"
}
```
- 期望：200

#### TC-13 非管理员访问（异常）

- 使用普通用户 token 调用 `/admin/**`
- 期望：403

### 4.6 文档 ACL 管理

#### TC-14 创建文档

- Method: `POST`
- URL: `{{baseUrl}}/docs`
- Header: `Authorization: Bearer {{token}}`
- Body:
```json
{
  "title": "Doc1",
  "content": "Hello"
}
```
- 期望：200，保存 `docId`

#### TC-15 分配文档权限

- Method: `PUT`
- URL: `{{baseUrl}}/docs/{{docId}}/members`
- Header: `Authorization: Bearer {{token}}`
- Body:
```json
{
  "userId": <USER_B_ID>,
  "role": "VIEWER",
  "remove": false
}
```
- 期望：200

### 4.7 审计日志

#### TC-16 查看个人审计日志

- Method: `GET`
- URL: `{{baseUrl}}/users/me/audit?page=0&size=20`
- Header: `Authorization: Bearer {{token}}`
- 期望：200

#### TC-17 管理员查看指定用户审计日志

- Method: `GET`
- URL: `{{baseUrl}}/admin/users/{{userId}}/audit?page=0&size=20`
- Header: `Authorization: Bearer {{adminToken}}`
- 期望：200

#### TC-18 文档审计日志

- Method: `GET`
- URL: `{{baseUrl}}/docs/{{docId}}/audit?page=0&size=20`
- Header: `Authorization: Bearer {{token}}`
- 期望：200

## 5. 常见错误与排查

- 401 Unauthorized：未带 token 或请求了需要鉴权的接口
- 403 Forbidden：权限不足（非管理员调用 `/admin/**` 或非 Owner/Admin 修改 ACL）
- 400 Bad Request：字段格式或长度校验失败
- JSON parse error：JSON 不是标准格式（字段名没双引号）

## 6. 建议验收流程

1. 注册账号并登录
2. 忘记密码并重置
3. 修改昵称/联系方式
4. 上传头像并访问图片
5. 创建文档并分配 ACL
6. 查看用户/文档审计日志
7. 管理员调整用户系统角色
